# CloudMart

## Cloud-Native E-Commerce Platform

CloudMart is a cloud-native e-commerce application designed to demonstrate
modern cloud computing and DevOps practices.

## Technologies

- React
- Python
- FastAPI
- PostgreSQL
- Docker
- Kubernetes
- Jenkins
- GitHub
- AWS S3
- AWS RDS
- AWS Lambda
- AWS CloudWatch

## Architecture

The project will progressively evolve from a basic application into a
cloud-native microservices architecture.

## Project Goals

- Microservices architecture
- Containerization
- Kubernetes orchestration
- CI/CD automation
- Cloud storage
- Cloud database
- Serverless computing
- Monitoring and logging
- Hybrid cloud integration
